# PvP Max HP normalization implementation plan

> For agentic workers: use the executing-plans workflow; split settings/UI and native runtime work by file ownership.

**Goal:** Add an optional, host-authoritative Max HP normalization for active balanced PvP participants.

**Design:** Reuse `PvpStatLimit` for HP above a configurable baseline. Defaults are baseline 100, soft +50, hard +100; default toggle off (the stated assumption while the optional preference remained unanswered). Preserve current HP percentage on application/removal (approved by the user), without restoring a pre-match HP snapshot. Use stock synchronized fields so guests see the effective maximum. This temporary maximum also applies to participating players' PvE interactions during active PvP. Persist policy only, never normalized health or native stat inputs.

**Global constraints:** All friendly-fire modes and shared selection semantics; no guest installation or new network protocol; no deployment; no per-hit/per-frame allocations in steady-state reconciliation; native saves, equipment/costume changes, curses, death/revival and reconnects must not compound the projection. Keep source/decompilation/logs out of Git. Read AGENTS.md and official developer guidance.
