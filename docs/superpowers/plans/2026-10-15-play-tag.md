# Play Tag implementation plan

**Goal:** Add host-authoritative bomb tag using shared friendly-fire match recovery.
**Architecture:** Keep one `CombatMatchRuntime` with explicit mode identity;
separate deterministic bomb progression from Unity integration and cosmetic FX.
**Tech stack:** C# / netstandard2.1, existing Harmony/Mirror native contracts.

## Constraints and confirmed rules

- No deployment or game launch; build/test with `-p:DeployMod=false`.
- One explosion ends the match. Recover dead entrants during shared cleanup.
- Each minimum-fuse holding consumes one of two per-player turns; third receipt
  explodes immediately. A 3-second initial fuse consumes the first turn.
- Each valid carrier kill passes to its victim and reduces fuse with integer
  `max(3, previous * 4 / 5)`. The new timer arms after that victim revives.
- Ordinary deaths do not pass or reset an already-armed fuse; Tag respawns after
  one second, existing modes retain three. K/D/A reset cannot replenish turns.
- Default fuse 30 seconds, whole-number range 3..3600, captured at match start.
- Freeze current connection receipts at enrollment; joins wait until next match.
  Selection/master-toggle edits stop; loss of the carrier or fewer than two
  current entrants stops safely. No old connection can regain participation.
- All enrolled pairs remain hostile while active. No live stat normalization or
  changes to existing damage scale, balance, targeting, K/D/A and PvE semantics.
- Exact main Leaf Explosion animation/audio, not its hit sparkle. Cosmetic-only
  transport must be independently verified before exposing a native attack object.

## Tasks and interfaces

- [x] Pure policy: create `Features/Combat/PlayTag/PlayTagBomb.cs` and dedicated
  executable tests. Constructor `(int playerCount, int initialCarrier, int seconds,
  double now)`; properties `Carrier`, `PreviousCarrier`, `Fuse`, `AwaitingRespawn`,
  `Resolved`; methods `TryPass(int killer, int victim, double now)`,
  `ArmAfterRespawn(int player, double now)`, `IsDue(double now)`,
  `Remaining(double now)`, `ConsumeExplosion(double now)`. Returns bool for state
  transitions. Integer indices refer only to the captured roster. Reject stale,
  noncarrier/self/out-of-range/expired passes; consume an explosion once.
- [x] Shared runtime: parameterize respawn delay and replace binary mode identity.
  Add `IsDeathmatch`, `IsPlayTag`, `CanStartPlayTag`, `StartPlayTag(out string)` and
  `DescribePlayTag()`. Add a Tag partial owning frozen entrants and pure bomb;
  tick expiry before revival, arm only after actual successful native revival,
  send changed-second bubbles, and clear owned state before stop callbacks.
- [x] Kill boundary: capture both participant receipts and match token in the
  existing death notice. Notify Tag only after complete, normal attributed player
  death; no extra-life/environmental/duplicate/exceptional/stale transfer. No epoch
  invalidation on pass. Native bomb expiry uses `Die(5,null)` for a live carrier
  within existing death guards; never repeat a death for an already-dead carrier.
- [x] Controls/config: `/one tag start|stop|status|resetkda|help`, `/one tag duration
  3..3600` and `duration reset`. Add Play Tag tab using shared participant editor.
  Session policy `PlayTagDuration`/`RecordPlayTagDuration`, session action
  `TrySetPlayTagDuration`. Nondefault saved duration uses preset v25; no match
  state is persisted. Existing Deathmatch controls must address Deathmatch only.
- [x] Cosmetic adapter: `PlayTagExplosion.Show(PlayerAvatar)` and `Reset()` under
  `Features/Combat/PlayTag`. Validate actual native resource/transport and isolate
  attack/collision/callback behavior; report a concrete blocker if exact cosmetic
  replication cannot be proven. Emit once at captured victim world position to
  host and stock guests; cleanup owned instances on normal finish/interruption.
- [x] Tests/review: deterministic rounding and finite allowance sequences;
  transfer/death/respawn ordering, initial expiry without passer, already-dead
  timeout, third-receipt expiry, resets/toggles/re-entry/floor/run transitions,
  nested native callbacks, existing modes, localization/presets/UI dispatch and
  native contracts. Add failing regressions before implementation. Independently
  review integrated changes before release build, commit and push.
